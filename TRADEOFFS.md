# Trade-offs

Every change to how yurigana reads breaks a few items to fix more. This file records each trade-off that
was accepted, what it costs, and the way out, so it can be resolved later instead of forgotten.

Each PR that changes readings adds its trade-offs here (or marks one resolved) in the same PR. Costs are
items broken on the evaluation sets (`python -m yurigana.evaluate --compare`), word list %: B1/B2 are
Tatoeba's halves (MeCab+IPAdic gold, noisy), NDL is the NDL huriganacorpus-aozora held-out authors (human
ruby). Forms and numbers only.

## Open

Costs are restated for post-war text (the target; pre-war NDL is report-only): "post-war" is the
estimated number of wrong words per typical book of ~19,000 kanji words, from 300 post-war books by
training authors read without their ruby lines (the form's frequency there times its error rate on a
hand-checked sample of bare occurrences; book ruby over-represents unusual readings, so its error rates
overstate bare text). "Accept" rows cost too little in post-war text to be worth a rule; "needs work"
rows say what would fix them. "dev" is the plain DEV set (2,996 random plain sentences from post-war
training-author books, 14,595 kanji words, blind Opus readings): misses there × 1.3 is per book; its
counts are small, so it ranks rows rather than measures them.
